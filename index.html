✳ What sets me apart

Lots of developers can build the screen. What I bring is the work around it: keeping it fast, testing it before it ships, and building pieces the next team can reuse.

Fast by default

I measure before I touch anything. At Flip Health, lazy loading, caching and code splitting took 30% off the first load and improved Core Web Vitals.

Tested before it ships

I write the tests alongside the feature. Our Jasmine and Karma suites cut regression bugs by about 40% and made releases a lot calmer.

Built to be reused

Shared component libraries, one filter component instead of ten, an editor we own instead of a library we fight. Less code for the next person.

Screen to database

When a feature needs an API, I write it in Node.js and Express with Sequelize and MySQL, so one person can see it through end to end.
